# Trading: a trade, its position, P&L and risk

The same diamond as the generic example (`a` → `b`, `c` → `d`), with domain names. The classes, fields and
audit entries are this domain's own; the dispatcher was generated by the Fluxtion compiler from
`TradingBuilder` and the log written by running it. Each node returns `true` only when its value changed, so an
input equal to the previous one stops at the top node.

```
        Trade (a trade price)
        |
        trade               holds the last trade price
       /     \
  position   pnl            market value = 10 units * price     P&L = 10 * (price - 100), bought at 100
       \     /
        risk                margin = 20% of market value + any unrealised loss; counts how often it runs
```

Inputs, in order: trade price = 98, 103, 103, 101.

- Every price change moves both `position` and `pnl`, so `risk` runs once per changed price (margin 216, 206,
  202). The compiler calls `pnl` before `position`; the siblings do not depend on each other.
- **The repeated trade at 103** (record 4, counting from 0, of the log's 6 records): only `trade` ran, with
  `price: 103, changed: false`. There is no `risk` entry: risk was not recalculated for that trade, and the
  counter stays at 2 until the trade at 101 makes it 3.

## Files

| Path | What it is |
|---|---|
| `src/main/java/com/acme/diamond/domain/trading/` | the event, the four nodes and the builder (written by hand) |
| `src/main/java/com/acme/diamond/domain/trading/generated/TradingProcessor.java` | the dispatcher, generated by Fluxtion |
| `src/main/resources/com/acme/diamond/domain/trading/generated/TradingProcessor.graphml` (and `.png`) | the graph the compiler derived |
| `domains/trading/trading-audit.yaml` | the audit log of one run |
| `domains/trading/run-console.txt` | what the runner printed on that run |

Run it again with `java -cp target/fluxtion-diamond.jar com.acme.diamond.host.DomainMain trading` (writes
`out/trading-audit.yaml`). In the analyser, open `trading-audit.yaml` with **Audit log ▸ Open log…** and the GraphML with
**Sources ▸ Open GraphML…**.
