# Mathematics: integer division

The same diamond as the generic example (`a` → `b`, `c` → `d`), with domain names. The classes, fields and
audit entries are this domain's own; the dispatcher was generated by the Fluxtion compiler from
`MathematicsBuilder` and the log written by running it. Each node returns `true` only when its value changed, so an
input equal to the previous one stops at the top node.

```
        Operand (an integer n)
        |
        dividend            holds the latest n
       /        \
  quotient    remainder     q = floor(n / 3)      r = n mod 3
       \        /
     recombination          3q + r, which gives back n; counts how often it runs
```

Inputs, in order: n = 4, 5, 5, 7.

- n = 5 after 4: the quotient stays 1 (`changed: false`), the remainder goes 1 → 2, and `recombination` still
  runs once, reading the quotient it kept: `quotient: 1, remainder: 2, value: 5, invocations: 2`.
- **The repeated 5** (record 4, counting from 0, of the log's 6 records): only `dividend` ran, with
  `n: 5, value: 5, changed: false`. There is no `recombination` entry: the identity check was not performed for
  that input, and its counter stays at 2 until n = 7 makes it 3.

## Files

| Path | What it is |
|---|---|
| `src/main/java/com/acme/diamond/domain/mathematics/` | the event, the four nodes and the builder (written by hand) |
| `src/main/java/com/acme/diamond/domain/mathematics/generated/MathematicsProcessor.java` | the dispatcher, generated by Fluxtion |
| `src/main/resources/com/acme/diamond/domain/mathematics/generated/MathematicsProcessor.graphml` (and `.png`) | the graph the compiler derived |
| `domains/mathematics/mathematics-audit.yaml` | the audit log of one run |
| `domains/mathematics/run-console.txt` | what the runner printed on that run |

Run it again with `java -cp target/fluxtion-diamond.jar com.acme.diamond.host.DomainMain mathematics` (writes
`out/mathematics-audit.yaml`). In the analyser, open `mathematics-audit.yaml` with **Audit log ▸ Open log…** and the GraphML with
**Sources ▸ Open GraphML…**.
