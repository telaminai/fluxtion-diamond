# Accounting: an invoice line

The same diamond as the generic example (`a` → `b`, `c` → `d`), with domain names. The classes, fields and
audit entries are this domain's own; the dispatcher was generated by the Fluxtion compiler from
`AccountingBuilder` and the log written by running it. Each node returns `true` only when its value changed, so an
input equal to the previous one stops at the top node.

```
        InvoiceLine (a net amount)
        |
        line                holds the latest line's net amount
       /    \
     tax    discount        tax = 20% of net, gross = net + tax     discount = 10% when net >= 1000, else 0
       \    /
       total                gross - discount, the amount to invoice; counts how often it runs
```

Inputs, in order: net = 400, 600, 600, 1200.

- On every line below 1000 the discount stays 0 (`changed: false`), and `total` still runs once because tax
  changed. The compiler calls `discount` before `tax`: the two siblings do not depend on each other, so either
  order is correct, and the generated dispatcher fixes one.
- **The repeated 600** (record 4, counting from 0, of the log's 6 records): only `line` ran, with
  `net: 600, changed: false`. There is no `total` entry: the invoice total was not recalculated for that line,
  and its counter stays at 2 until the 1200 line makes it 3 (`total: 1320`).

## Files

| Path | What it is |
|---|---|
| `src/main/java/com/acme/diamond/domain/accounting/` | the event, the four nodes and the builder (written by hand) |
| `src/main/java/com/acme/diamond/domain/accounting/generated/AccountingProcessor.java` | the dispatcher, generated by Fluxtion |
| `src/main/resources/com/acme/diamond/domain/accounting/generated/AccountingProcessor.graphml` (and `.png`) | the graph the compiler derived |
| `domains/accounting/accounting-audit.yaml` | the audit log of one run |
| `domains/accounting/run-console.txt` | what the runner printed on that run |

Run it again with `java -cp target/fluxtion-diamond.jar com.acme.diamond.host.DomainMain accounting` (writes
`out/accounting-audit.yaml`). In the analyser, open `accounting-audit.yaml` with **Audit log ▸ Open log…** and the GraphML with
**Sources ▸ Open GraphML…**.
